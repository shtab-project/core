# Плагины Shtab

Плагин — это папка с двумя файлами:

```
plugins/<id>/
  plugin.yaml          — манифест: что это, куда публиковать, как защищать
  docker-compose.yml   — сами сервисы (любой open source с Docker-образом)
```

Ядро (этап 4 дорожной карты) будет читать манифест и:

1. поднимать compose-проект `shtab-<id>`;
2. вешать на сервисы Traefik-маршруты по `routes`;
3. закрывать их входом Shtab по `auth` (Authentik forward-auth или OIDC);
4. показывать плитку в портале;
5. если есть `mcp` — подключать инструменты плагина к MCP-шлюзу, чтобы
   ChatGPT и Claude могли ими пользоваться.

Пока это черновик формата — пример в [uptime/plugin.yaml](uptime/plugin.yaml).
