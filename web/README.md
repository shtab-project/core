# Веб-интерфейс Shtab

Пока пусто — фреймворк ещё не выбран (React или Vue).

План:
- портал с плитками сервисов;
- канбан по `GET /api/board`, перетаскивание → `PATCH /api/tasks/{id}/status`;
- граф связей заметок;
- PWA, чтобы открыть с телефона как приложение.

TS-клиент API генерируется из OpenAPI ядра (`http://api.shtab.localhost/openapi.json`),
типы вручную не дублируем.
